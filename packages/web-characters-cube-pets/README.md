# @n1h/web-characters-cube-pets

Kenney's 24 [Cube Pets](https://kenney.nl/assets/cube-pets), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), as [`@n1h/web-characters`](https://github.com/n0t-invented-here/catwalk) models.

```ts
import { cat } from "@n1h/web-characters-cube-pets/cat";              // one animal: its file and the shared texture
import { CUBE_PETS } from "@n1h/web-characters-cube-pets";            // all 24, by name
import { PETS, petLabel } from "@n1h/web-characters-cube-pets/spec";  // the names, without the files
```

- One module per animal, so a build ships only the animals a page imports.
- The animals: beaver, bee, bunny, cat, caterpillar, chick, cow, crab, deer, dog, elephant, fish, fox, giraffe, hog, koala, lion, monkey, panda, parrot, penguin, pig, polar, tiger.
- They idle, walk, run and dance. The chick, the parrot and the penguin also eat.
- Licence: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); Kenney's file is `assets/License.txt`.

Reference: [packs](https://github.com/n0t-invented-here/catwalk/blob/main/docs/packs.md).
